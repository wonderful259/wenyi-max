# 文类指南 · 非虚构科技报道

默认画像：信息型，偏硬～偏中（自由度 3–5），准确优先，同时不能有翻译腔。参照系是成熟中文科技/财经媒体的写法（《经济学人》中文版、财新、机器之心、极客公园），而不是逐句对译。标题和导语属呼唤型，可以放开。

## 1. 准确性硬规则

- **情态和信源词一个都不能丢**：may / might / could / reportedly / allegedly / according to / is expected to / claims，分别对应「可能」「据报道」「据称」「据……」「预计」「声称」。这些词决定了报道的可信度边界。
- **不添加原文没有的信息**：不替作者解释，不补背景。确有必要时用「（译注：……）」并在翻译报告里列出；默认少用。
- 时间表述照原文：last week / this year 不要换算成具体日期。
- 直接引语保留说话者的口吻（CEO 的公关腔、研究者的谨慎、批评者的尖刻）。

## 2. 数字与单位

- billion = 十亿，trillion = 万亿：`$3.2 billion` → 32 亿美元，`1.5 trillion` → 1.5 万亿。**数字逐个核对，这是最容易出事故的地方。**
- percent 和 percentage point 分开：「上升 3 个百分点」≠「上升 3%」。
- half a dozen = 6、a dozen = 12、fortnight = 两周、a couple of = 两（口语约数除外）：不要译成「五六个」「十几个」。
- 货币保留原币种，不换算人民币。
- 数字一律用阿拉伯数字，「32 亿」这种中文量级单位和数字之间不加空格。

## 3. 专名处理（风格确认时请用户选一种方案，全书统一）

| 类型 | 默认处理 |
|---|---|
| 有通行中文名的公司 | 用中文：微软、谷歌、苹果、英伟达、亚马逊、特斯拉 |
| 没有通行中文名的公司、产品、模型 | 保留英文：OpenAI、Anthropic、Meta、GPT-5、Claude、Llama |
| 知名人物 | 用通行译名：萨姆·奥尔特曼、黄仁勋、埃隆·马斯克 |
| 一般人物 | 方案 A：中文音译，首次出现括注英文；方案 B：保留英文原名（科技媒体常见） |
| 机构 | 首次出现中文全称并括注英文缩写，之后用缩写或简称：美国联邦贸易委员会（FTC） |
| 期刊、媒体 | 书名号：《自然》《科学》《纽约时报》 |

## 4. 术语

- AI 领域常用对照（术语表里可以直接预置）：large language model 大语言模型、inference 推理、training 训练、alignment 对齐、hallucination 幻觉、agent 智能体、benchmark 基准测试、fine-tuning 微调、open-weight 开放权重、compute 算力。
- `token` 有分歧（词元 / token / 令牌），`reasoning model`、`frontier model` 也有不同叫法，在风格确认时让用户选。
- 其他学科名词按「术语在线」规范名；新兴词汇没有规范名的，首次出现可括注英文。

## 5. 句子层面

- 英文报道爱用长修饰语开头的句子（`A former Google engineer who left the company in 2023 to found…`），中文拆开：先交代人，再说事。
- 被动句大多转主动或无主句；`It is believed that…` → 「一般认为」。
- 抽象名词主语转成具体的人或事：`The adoption of AI by hospitals has…` → 「医院用上 AI 之后……」。
- 转折、因果关系照原文的逻辑走，但连接词能省则省，靠语序体现。
- 段落以信息为单位，不随意合并或拆分（原书排版和脚注都依赖段落结构）。

## 6. 标题、小标题、导语

- 标题可意译，追求信息量和吸引力，但**不能加入原文没有的判断**。
- 双关、俚语标题：先保信息，再尽量保趣味，保不住就舍弃。
- 小标题简短，用名词短语或短句。

## 7. 注释、链接、图表

- 脚注号、尾注、链接由 `<N>` 标签保留，必须原位放回。
- 尾注（Notes）章节要翻译；参考文献条目（作者、书名、期刊名）**保留原文**，只翻译说明性的文字。
- 图片说明（figcaption）照常翻译；图片里的文字无法处理，在翻译报告里提醒。
- 索引（Index）章节：默认保留原文（中文页码对不上，翻译意义不大），在风格确认时告知用户。
