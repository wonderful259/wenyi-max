# 英译中方法论核心（叶子南《高级英汉翻译理论与实践》）

> 浓缩自 [en-zh-max](https://github.com/3060226349kk-cmd/en-zh-max)（MIT）。翻译、润色、审校三个阶段都以本文为准；细节查同目录的 `techniques.md`、`translationese-symptoms.md`、`text-analysis-and-qa.md`。

## 统领原则：读者中心

每个翻译决策最终都追溯到一个问题：**这个中文读者是谁，在什么语境下读？** 拿不准时回到这里。

五条原则：
1. **先分析文本再动笔**：七维度诊断 + 自由度评分，先定位再翻译。
2. **以译入语为依归**：总方向是靠近读者、发挥汉语优势。
3. **灵活变通**：摆脱原文语言结构的束缚（奈达）。
4. **保护汉语纯洁性**：警惕西化汉语。
5. **文学翻译忌释义**：「释义是文学翻译的大敌」——保留原文的语言形式（意象、句式节奏、作者刻意的偏离）优先于转述内容。

## 英→中三重根本差异

1. **形合 vs 意合**：英语靠 because / although / which / that 显化逻辑，汉语靠语序和语境暗示。英语的连接词、关系代词、冠词在汉语里大多可省。逐个对应成「因为」「虽然」「其」「的」= 臃肿、「的的不休」。
2. **抽象名词作主语**：`The realization of…`、`The confidence that…` 直译会让译文漂浮、没有人味。汉语偏好具体的人或物作主语。
3. **长定语从句**：英语定语可以向右无限扩展，汉语定语必须前置且容量有限。拆成流水短句，或转成状语、独立句。

## 文本画像（阶段 2 必填，写进 style-guide.md）

| 项 | 取值 | 说明 |
|---|---|---|
| 档位 | 偏硬 / 偏中 / 偏软 | 硬=科技/法律/经贸；中=新闻/教科书/科普；软=文学/散文/评论 |
| 自由度 | 1–10 | 合同≈2–3，科技报道≈3–5，类型小说≈6–8，文学性强的小说≈7–9 |
| 文本类型 | 表达 / 信息 / 呼唤（纽马克） | 小说=表达型；科技报道=信息型（标题与导语偏呼唤型） |
| 语域 | 正式 / 中性 / 口语 / 混合 | 按人物分别记录 |
| 语域脏度 | 1–5 | 1 零脏字；2 可俗不脏；3 粗鄙自由；4 脏字对等；5 猎奇极限 |
| 策略 | 准确优先 / 平衡 / 流畅优先 | 由档位推出 |

- **偏硬（1–3）**：贴原文逻辑，选词精准，**准确 > 流畅**；术语用固定译法；某些「西化」是为精确付的合理代价。
- **偏中（4–6）**：平衡，默认交际翻译。
- **偏软（7–9）**：发挥意合与汉语之美，可调结构、可换形象，**流畅、效果优先**。
- 脏度判定：读前 500–1000 词看贬称、骂詈、性描写、暴力描写的密度和强度；拿不准宁高不低。学术/非虚构文本含脏字时，**不得自定脏度，必须在风格确认时问用户**。脏度和软硬是两回事，各自判定。
- 涉及性/身体直白描写时，**语域对齐优先于归化**：原文粗就译粗，原文临床就译临床，原文文雅就译文雅。词表见 `libertine-vocabulary.md`（萨德式浪荡文学）和 `literary-fiction-sexual-register.md`（当代文学的混合语域）。

## 翻译动作（阶段 4，每段都要走）

1. **理解 → 脱离语言外壳**：读懂后抛开英文词句，先在脑中形成意义和画面，再用中文重构。结构纠缠的短语用「解包袱法」理清隐含的语义关系（`poverty tour` →「对贫困地区的访问」）。
2. **按档位初译，意合优先**：能不用连接词就不用；长句拆成流水短句；被动转主动；定语别堆在名词前。翻译单位随档位变：硬文本以词组为单位，软文本以句群为单位，尽量往大里取。
3. **自查翻译腔**（`translationese-symptoms.md` 八条快速诊断）：连接词冗余、前置定语过长、的的不休、被动滥用、抽象名词主语、习语硬译、套语错位、修饰关系不清。修法查 `techniques.md`：词性转换、增词、减词、分句、合句、移位、正反译。
4. **隐喻决策**：基本/图像图式隐喻（旅程、上下、冷热）可直译；可以直译不等于应该直译，看档位；文化专属隐喻要么糅合要么舍弃（`text-analysis-and-qa.md` 小节 B）。
5. **音韵节奏**（软文本才放开）：读出声；双音节、四字格、「偶字易适，奇字难平」；并列词组尽量配偶字。硬文本点到为止。

## 润色边界（防止方法论用过头）

- **不要过度归化**：别为了「地道」抹掉原文风格、术语精度、文化标记。西化是连续体，文本价值越高越能容纳异化。
- **不要堆砌四字成语**：节奏是手段不是目的，堆多了显得卖弄、失真。
- **文学翻译不要释义**：作者刻意的形式（短句、重复、长句堆叠、非常规搭配）要保留；英语体系本身的形合特征才归化。
- **自由度越低越克制**。

## 准确性红线（阶段 5 审校用）

叶子南六维校验：
1. **重心转移**：语义重心被挪到次要成分上了吗？（`A is B` 擅自译成 `B is A`）
2. **语义遗漏**：关键语义要素、情态（could / might / do know）、程度、时间、否定是否丢了？
3. **结构意义丢失**：原文靠结构表达的意义（强调、对比、悬念）还在吗？
4. **过度显化**：是否把原文刻意隐含的信息说破了？
5. **逻辑偏移**：因果、让步、条件、转折有没有被改？
6. **语域不匹配**：正式对正式，口语对口语，粗话对粗话。

> 放松准确性 ≠ 理解错误。**理解错误没有原谅的余地。**
