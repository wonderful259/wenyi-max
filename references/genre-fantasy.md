# 文类指南 · 奇幻小说

默认画像：表达型，偏软（自由度 6–8）。史诗奇幻的叙述可以略带书面感；都市奇幻、喜剧奇幻口语化。

## 1. 人名

- 普通人名音译，参照新华社《英语姓名译名手册》用字习惯，女性名可选柔和的字但别过度女性化。
- **会说话的名字**（绰号、称号）意译：Strider 神行客、Wormtongue 佞舌、Kingslayer 弑君者、the Hound 猎狗。
- **动物、魔物、物件的名字同样适用**，而且更容易出错：主角给骨狗起名 Bonedog（骨狗），把会找东西的老鼠叫 Finder，读者一眼就懂这是随手起的、带着用途的名字。音译成「芬德」，读者只看到一个陌生的洋名，起名的那份随意和幽默全丢了。可选「觅觅」「寻寻」「找找」这类叠字小名，或「寻物鼠」这类功能名，按人物说话的语气挑。
- **判断方法**：把名字当普通英文读一遍——是 finder / bonedog / little mouse / thistle 这种词典里查得到、母语读者会读出意思的，就意译；是 Marra / Vorling / Kania 这种只有声音的，就音译。拿不准时问一句：英语读者第一次看到这个名字，会不会笑、会不会联想到什么？会，就意译。
- 普通英语单词恰好也是常见西方人名的（Grace、Hope、Rose、Will），按人名音译；但原文明显在玩字面义（角色名就叫 Hope，还被拿来做双关）时意译或加处理。
- 建术语表时，每个名字条目写 `meaning`（字面义，没有就写空）；有字面义还决定音译的，加 `"name_mode":"sound"` 并写理由。`check_terms.py` 会对「英文是普通单词、译名却是纯音译」的条目报警告。
- 原著已有通行中译本的系列，**沿用通行译名**（如《冰与火之歌》《魔戒》《时光之轮》），风格确认时说明采用的是哪个版本。
- 姓 + 名 + 称号的长串（Daenerys Stormborn of House Targaryen），首次全译，之后按原文的简称习惯走。

## 2. 地名

- 英语词根组成的地名**意译**：Rivendell 幽谷、Mirkwood 黑森林、the Shire 夏尔（已约定俗成的音译照用）、Winterfell 临冬城、King's Landing 君临。
- 虚构语言的地名**音译**，同一语言的地名用字风格保持一致（如精灵语地名统一用较雅的字）。
- 地理通名统一：-wood 林/森林、-fell 原/岭、-mere 湖、-shire 郡。

## 3. 头衔与称谓

- 一套爵位体系一套译法，写进术语表：Lord / Lady / Ser / Maester / Your Grace / Your Highness。
- Ser → 爵士；Lord 视语境「大人 / 公爵 / 伯爵 / 领主」；Your Grace 对君主「陛下」、对公爵「大人」——**同一个英文词在不同对象面前译法不同，要在术语表备注里写清规则**。
- 称谓的亲疏变化（从 Lord Stark 到 Ned）往往代表关系变化，译文要跟着变。

## 4. 语域：仿古，不是古文

- 叙述用规范白话，可以略带书面感；**不要半文半白，也不要武侠腔**（除非原文本来就有意模仿某种古雅文风）。
- thee / thou / thy 这类古语：用句式和语气体现庄重（「汝」「尔」只在原文刻意仿古、且人物身份合适时少量使用）。
- 对话按人物身份分层：贵族、学士、士兵、平民说话的词汇和句长都不同，在 style-guide 的人物表里逐个写清。
- **避免现代词**：「OK」「搞定」「效率」「心理阴影」这类词会戳破异世界感。

## 5. 魔法体系与种族

- 一套魔法体系一套构词规则（如所有法术等级用「环」，所有学派用「系」），建术语表时一次定下。
- 种族名：已约定俗成的照用（elf 精灵、dwarf 矮人、orc 半兽人或兽人——看所在系列的惯例），自创种族按理据意译或音译。

## 6. 诗歌、歌谣、预言

- 优先保留**意象和韵律感**，其次押韵；不必逐行对应，但节数和行数尽量对应（原书排版靠它）。
- 预言往往一语双关，译文要保留歧义，不能为了通顺把预言「解」出来。
- 难以两全的地方在翻译报告里列出取舍。

## 7. 誓言、咒骂、俗语

- 虚构的咒骂和俗语直译，保留异世界色彩：Seven hells! 七层地狱！、By the gods 诸神在上。
- 不要换成中文现成的俗语（「我的老天爷」「阿弥陀佛」），宗教和文化色彩不对。
- 誓词、祝福、咒语、童谣在书里**往往重复出现、互相呼应**（同一段祝福在命名礼上念一遍，几十页后被人原样引用）。第一次定下的译法就是锁定译法，后文逐字照用；`recurring_phrases.py` 会把这类句子扫出来，收进术语表（category `sentence` / `phrase`）。

## 8. 代词：跟原文，不跟物种

- 奇幻里大量非人角色：骨头拼成的狗、木偶、魔像、会说话的鸡、亡灵。**原文用什么代词就译什么**：he → 他，she → 她，it → 它。不要因为「它是动物 / 是物件」就把 he 改成「它」，也不要因为「它会说话」就把 it 改成「他」。
- **代词切换是写作手段**。同一个对象在原文里先是 it、后来变成 he（或反过来），往往标记着角色态度变化（从「那东西」到「他」）、身份揭晓，或者就是笑点——比如一个人偶被当成物件一路用 it，直到它开口说话，叙述突然改用 he，读者跟着吓一跳。译文统一成「它」，这个转折就没了。
- 原文刻意含糊（不说是男是女、是人是物）制造悬念时，中文也要设法保持含糊（用名字、称谓或省略主语代替代词），不要提前替读者揭晓。
- 审校时把「代词与原文不一致」当准确性错误（pronoun）处理，不当风格问题。

## 9. 数量词

- 英语里有些量词本身是精确数：half a dozen = 六，a dozen = 十二，a score = 二十，fortnight = 两周，a brace of = 一对。**按精确数译**，不要顺手改成「五六个」「十几个」。原文本身是约数（dozens of、a dozen or so、at least a dozen）时才用约数。
- `qa_scan.py` 会把 half a dozen → 五六 这类情况标成【严重】，fortnight 等没找到对应译法的标成【提示】。
