# 中文终审清单：翻译腔 + AI 腔

> 代替 en-zh-max 校验链里的 prose-reviewer / humanizer / humanizer-zh（这几个外部 skill 未必装了，这里把要点收进本地）。审校阶段对照原文核完准确性之后，用本清单过一遍中文。**只改表达，不改语义；不动 ⟦N⟧ 和 <N> 标签；不改术语表译名。**

## A. 翻译腔（英语结构残留）

| # | 症状 | 例 | 修法 |
|---|---|---|---|
| A1 | 连接词逐个对应 | 因为……所以……；虽然……但是…… 成对出现 | 删掉一半，靠语序表达逻辑 |
| A2 | 的的不休 | 这个国家的政府的新的政策 | 拆句、改动宾、删「的」 |
| A3 | 前置定语过长 | 一个在 2023 年离开公司去创办自己的初创企业的前谷歌工程师 | 先交代人，再说事：一位前谷歌工程师，2023 年离职创业 |
| A4 | 被动滥用 | 他被告知…… / 这一发现被认为…… | 主动或无主句：有人告诉他 / 一般认为 |
| A5 | 抽象名词作主语 | 对失败的恐惧使他犹豫了 | 他怕失败，犹豫了 |
| A6 | 代词过多 | 他抬起他的手，他看着他的手表 | 汉语承前省略：他抬手看表 |
| A7 | 「一个」「一种」泛滥 | 一种奇怪的感觉 / 一个巨大的问题 | 多数可删 |
| A8 | 「进行」「作出」「加以」虚动词 | 进行了讨论 / 作出了决定 | 讨论了 / 决定 |
| A9 | 「当……的时候」「在……之后」开头 | 当他走进房间的时候 | 他一进屋 / 他走进房间 |
| A10 | 习语硬译 | 房间里的大象 | 看档位：软文本可保留意象，否则换成「心照不宣的难题」 |
| A11 | 「-ly」副词全译成「地」 | 他缓缓地、轻轻地、小心翼翼地 | 只留一个，或转成动词 |
| A12 | 时态词滥用 | 他已经曾经去过了 | 留一个时态标记就够 |

## B. AI 腔（模型写作的惯性）

| # | 症状 | 修法 |
|---|---|---|
| B1 | AI 高频词：此外、值得注意的是、至关重要、深入探讨、不可或缺、格局、织锦、画卷、交响、见证、彰显、赋能 | 原文没有对应强调就删；换成具体说法 |
| B2 | 原文没有的总结句、升华句 | 删。译文不比原文多说一句话 |
| B3 | 三段式排比（原文只有两项或没有排比） | 按原文项数 |
| B4 | 「不是……而是……」否定式对举（原文没有） | 改回原文的直陈 |
| B5 | 破折号滥用（原文用逗号或冒号的地方） | 跟原文标点功能走 |
| B6 | 「仿佛」「似乎」「不禁」「微微」「缓缓」高频出现 | 原文有 as if / seemed 才用；其余删 |
| B7 | 四字格堆砌（一句三个以上） | 拆掉一半，换成白话 |
| B8 | 情感词放大（原文 sad → 悲痛欲绝） | 按原文强度 |
| B9 | 句长单一，每句都一样长 | 长短交错，跟着原文节奏走 |
| B10 | 对话太书面、太完整 | 口语里省主语、用语气词、句子不完整都正常 |

## C. 中文规范

- 标点：中文全角；引号默认用「」『』（外层「」、内层『』，用户偏好；风格确认时改成“”‘’的按 manifest 的 quote_style），同一本书不混用；省略号「……」；破折号「——」；书名、报刊、电影用《》。（`fill_translation.py` 会自动规范化大部分，但「该用句号还是逗号」这类判断要人做。）
- 数字：见各文类指南。
- 量词搭配：一艘飞船、一座城、一头巨龙、一台机器。
- 「的」「地」「得」用对。
- 不出现「他/她/它」混用指同一对象。

## D. 自检方法

1. 遮住原文，只读译文：读着顺不顺？像不像中文作家写的？
2. 抽三段读出声：有没有拗口的地方、换气点对不对？
3. 统计提示：`qa_scan.py` 报告末尾给出「被」字密度、代词密度和高频可疑词，数字偏高的章节重点看。
